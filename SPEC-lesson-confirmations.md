# Спецификация: подтверждения занятия

## Цель
Хранить и показывать подтверждения непосредственно в занятии. Для каждого ученика
обязательны: ответ ученика, хотя бы одного связанного родителя и преподавателя занятия.

## Контракт
- `green`: ученик, один родитель и преподаватель ответили «Да».
- `red`: любой обязательный участник ответил «Нет».
- `yellow`: отказов нет, но обязательных ответов недостаточно.
- Прошедшие и начавшиеся занятия не принимают новые подтверждения.
- Отказ не изменяет состав занятия автоматически.
- Если связанного родителя нет, родительское подтверждение не требуется.
- Если родители связаны с учеником, достаточно ответа «Да» одного из них; второй может не отвечать.
- Если родители связаны, но никто не подключён к MAX, карточка показывает причину ожидания.

## Стек и структура
Python 3.13, FastAPI 0.116+, SQLAlchemy 2.0.41+, pytest 8.4+.
Сервер: `bot/src/krit_bot/communications.py`, `bot/src/krit_bot/learning.py`.
Тесты: `bot/tests/test_communications.py`, `bot/tests/test_learning_api.py`.

## Границы
- Всегда: сохранять историю и идемпотентность callback.
- Не делать: автоматически исключать ученика при отказе.
- Совместимость: существующие запросы и ответы остаются читаемыми.

## Критерии готовности
Карточка получает по API ожидаемых отвечающих, ответы, причины и сводный статус; ответы
по прошедшему занятию отклоняются; ответ учителя учитывается.
