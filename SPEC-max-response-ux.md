# Спецификация: ответ в MAX

## Цель
После ответа пользователь сразу видит результат и не может повторно нажать ту же кнопку.

## Контракт
- Целый ответ удаляет всю клавиатуру исходного сообщения.
- В поурочном режиме удаляется отвеченная строка; оставшиеся занятия доступны.
- После последнего ответа клавиатура удаляется полностью.
- Callback подтверждается текстом «Ответ сохранён».
- Повторный callback не меняет данные повторно.

## Реализация
Используется официальный `POST /answers` с объектом `message`; пустой массив
`attachments` удаляет inline-клавиатуру.

## Проверка
Тесты обработчика и webhook проверяют БД, подтверждение callback и изменённую клавиатуру.
